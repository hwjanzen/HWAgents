# Copilot-Wissen aufbauen

## Zweck
Prozessdokumentationen so strukturieren, dass sie von Copilot-Agenten
zuverlässig gelesen und angewendet werden können.

## Anforderungen an agentenfähige Dokumentation
Eine Dokumentation ist agentenfähig wenn sie folgende Eigenschaften hat:

1. **Klare Struktur** — Überschriften, nummerierte Schritte, keine Fließtextblöcke.
2. **Eindeutige Begriffe** — Keine Synonyme für denselben Begriff.
3. **Explizite Entscheidungen** — Wenn/Dann-Regeln statt impliziter Logik.
4. **Vollständige ERP-Objekte** — Tabellenname, Listenname, Aktionsname exakt benennen.
5. **Abgegrenzte Abschnitte** — Jeder Abschnitt beantwortet genau eine Frage.

## Ablauf
1. Bestehende Dokumentation auf Agentenfähigkeit prüfen.
2. Schwachstellen identifizieren (fehlende Struktur, unklare Begriffe, implizite Logik).
3. Dokumentation nach obigen Anforderungen überarbeiten.
4. Prozessverantwortlichen bestätigen lassen.
5. Aktualisierte Version speichern.

## Regeln
- Inhalt nicht verändern — nur Struktur und Klarheit verbessern.
- Keine Informationen ergänzen die nicht bestätigt sind.
