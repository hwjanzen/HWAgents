# V0.1 Agent Case Contract

## Zweck
Dieses Contract-Dokument definiert das gemeinsame Vorgangsobjekt fuer die Orchestrierung zwischen Looka, Ingo, Artika, Erkan und Tanja.

## Schema
- JSON Schema: schemas/v01-agent-case-contract.schema.json
- Contract-Version: v0.1

## Pflichtfelder
- contractVersion
- caseId
- source.channel
- classification
- documentType
- status
- updatedAt

## Klassifikation zu Dokumentart
- order_item_clear -> sales_order
- order_item_unclear -> sales_order
- quote_item_clear -> sales_quote
- quote_item_unclear -> sales_quote

## Statusmodell
- initiated
- rejected_by_ingo
- routed_to_artika
- failed_by_artika
- routed_to_erkan
- failed_by_erkan
- completed
- handover_tanja

## Ergebnisvertraege
- Looka liefert classification plus optional extrahierte Positionen.
- Artika liefert:
  - positiv mit debitorNo und items
  - negativ mit failureReason
- Erkan liefert:
  - positiv mit documentNo
  - negativ mit failureReason

## V0.2 Erweiterung (rueckwaertskompatibel)
- Der Contract bleibt v0.1, wird aber um optionale Artika-Recherchefelder erweitert:
  - artikaResult.debitorSearch
  - artikaResult.articleReferenceSearch
- Beide Felder liefern je einen Status:
  - unique
  - ambiguous
  - not_found
- Bei ambiguous liefert Artika Kandidatenlisten:
  - Debitoren: debitorNo + name
  - Artikel: itemNo + description
- Ingo waehlt in V0.2 bei Mehrdeutigkeiten nicht automatisch aus, sondern uebergibt an Tanja.

## Abschlussmeldung an Tanja (fixer Output-Contract)
- Feldname: tanjaOutput
- recipient: immer tanja
- outcome:
  - success bei status completed
  - failed bei rejected_by_ingo, failed_by_artika, failed_by_erkan, handover_tanja
- Pflicht bei Erfolg:
  - documentType
  - documentNo
- Pflicht bei Misserfolg:
  - failureReason
- Pflicht in allen Faellen:
  - subject (Mail-Betreff)
- message ist immer Pflicht und enthaelt die human-lesbare Abschlussmeldung.

## Fehlgruende V0.1
- missing_required_information
- unusable_email_content
- customer_not_found
- ambiguous_customer
- item_not_found
- item_reference_not_found
- ambiguous_item_reference
- bc_creation_failed
- manual_clarification_required
